SILVIA SKI-AUFENTHALT – UPLOADPAKET

Struktur:
- index.html = Hauptseite und zentrale Einstiegsdatei
- overview.html = Überblick
- unterkunft.html = Unterkunft
- anreise.html = Anreise
- geschenk.html = Geschenk
- styles.css = gemeinsames Design
- assets/ = Seitenbilder
- icons/ = App-Icons, inklusive 50 unten rechts
- manifest.webmanifest + sw.js = PWA/Offline-Funktion

WICHTIG:
Alle Dateien und Ordner direkt in das ROOT deines GitHub-Repositories silvia-ski-weekend hochladen.
index.html darf NICHT in einem Unterordner liegen.

Danach:
1. Commit auf main.
2. GitHub > Actions > Deploy Now: Orchestration.
3. Run workflow > main.
4. Nach erfolgreichem Lauf IONOS-Adresse öffnen.
5. iPhone: Safari > Teilen > Zum Home-Bildschirm > Hinzufügen.

Das Hauptmotiv enthält bewusst KEINE eingebetteten Texte wie
"SKI WEEKEND", "GUTSCHEIN" oder "Einlösbar am 24.01.2027".
Texte werden ausschließlich als HTML dargestellt.
